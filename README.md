# Netflix Content Analysis: Data Cleaning, Exploratory Data Analysis, and Visualization using Python

## Project Overview

This project focuses on cleaning, processing, and visualizing the Netflix Movies and TV Shows dataset using Python.

The objective is to demonstrate practical data analytics skills including:

* Data Cleaning
* Missing Value Handling
* Duplicate Removal
* Data Transformation
* Exploratory Data Analysis (EDA)
* Data Visualization

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## Dataset

Netflix Movies and TV Shows Dataset from Kaggle.

## Project Workflow

1. Dataset Loading
2. Data Inspection
3. Missing Value Handling
4. Duplicate Removal
5. Data Type Conversion
6. Feature Engineering
7. Exploratory Data Analysis
8. Data Visualization
9. Insight Generation
10. Report Preparation

## Visualizations

* Movies vs TV Shows
* Top Countries Producing Content
* Rating Distribution
* Release Year Trend
* Top Genres

## Key Insights

* Movies dominate Netflix content.
* United States contributes the highest number of titles.
* TV-MA is the most common rating category.
* Content growth accelerated after 2015.
* Drama and International Movies are among the most popular genres.
